# snakeco-legal

Public pages for the SnakeCo Android game by DGM Technology OÜ: Privacy Policy and Terms of Use in English and
Spanish. Served with GitHub Pages at <https://dfgonzalez88.github.io/snakeco-legal/>.

| Page | URL |
|---|---|
| Privacy Policy (EN) — used in Google Play Console | https://dfgonzalez88.github.io/snakeco-legal/en/privacy.html |
| Terms of Use (EN) | https://dfgonzalez88.github.io/snakeco-legal/en/terms.html |
| Política de privacidad (ES) | https://dfgonzalez88.github.io/snakeco-legal/es/privacy.html |
| Condiciones de uso (ES) | https://dfgonzalez88.github.io/snakeco-legal/es/terms.html |

The source of these files lives in the private SnakeCo repository under `docs/legal-site/`. Edit them there, then copy
them here. The app links to these exact URLs (string resources `about_privacy_url` / `about_terms_url`), so never
rename or move the files.

When SnakeCo switches to free with ads, section 12 of the privacy policy becomes active: remove the "not active"
box, update the effective date and the permissions table, and add an `app-ads.txt` if AdMob asks for one.
